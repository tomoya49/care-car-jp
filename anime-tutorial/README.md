# はじめてのアニメづくり 🎬

プログラミングで、短いアニメ「まるちゃんの一日」を作るチュートリアルです。
**必要なのはブラウザ（Chrome や Safari）だけ**。何もインストールしなくて大丈夫です。

## 見かた

1. `step1.html` などのファイルをパソコンに保存する
2. ダブルクリックする → ブラウザでアニメが動きます
3. ファイルをメモ帳（Windows）やテキストエディット（Mac）で開くと、中身を書きかえられます
   （おすすめのエディタは無料の「VS Code」です）
4. 書きかえて保存したら、ブラウザで再読み込み（F5 / ⌘R）すると反映されます

## アニメの仕組み：パラパラ漫画

アニメは「少しずつ違う絵を、すばやく何枚も見せる」ことで動いて見えます。
テレビアニメは 1秒に 24枚くらい、このチュートリアルは 1秒に約 60枚 描いています。

```
消す → 少しずらして描く → 消す → 少しずらして描く → …（くり返し）
```

## 3つのステップ

| ファイル | 学ぶこと |
| --- | --- |
| `step1.html` | **1枚の絵を描く**。四角・丸・線で、空と地面とキャラを描く |
| `step2.html` | **動かす**。位置を少しずつ変えながら描きなおす（パラパラ漫画） |
| `step3.html` | **お話にする**。「何秒目に何が起きるか」の台本（タイムライン）で場面を作る |

### 覚える言葉はこれだけ

- **canvas（キャンバス）** … 絵を描く画用紙
- **座標 (x, y)** … 画用紙の上の位置。**左上が (0, 0)**、右に行くと x が増え、**下に行くと y が増える**
- **fillRect / arc** … 四角を塗る / 丸を描く命令
- **関数（function）** … 「描き方のレシピ」に名前をつけたもの。`drawCharacter(320, 290)` で何度でも呼べる
- **requestAnimationFrame** … 「次のコマも描いてね」とブラウザに頼む命令。これでアニメが続く

## 自分でいじってみよう（おすすめ順）

1. **色を変える**：`step1.html` の `"#ffcc66"`（キャラの色）を `"#ff88cc"` にするとピンクに
2. **速さを変える**：`step2.html` の `x = x + 2;` の `2` を `5` にすると速く走る
3. **セリフを変える**：`step3.html` の `"こんにちは！"` を好きな言葉に
4. **台本を変える**：`step3.html` の `if (t < 4)` の `4` を `2` にすると、早く到着する
5. **新しい場面を追加**：`if (t >= 10 && t < 12) drawBubble(x + 95, y - 150, "おやすみ");` を足してみる

壊れても大丈夫。元に戻せばいいだけです。どんどん試してみてください！
